# Геометрия шрифтовых Мусхафов — 2026-09-08

## Повторная приёмка: точность печатной страницы ещё не подтверждена

Пользователь отклонил прежнюю раскладку: строки были прижаты к правому краю.
Причина — продвижение по `ink bounds` вместо HarfBuzz advances и добавленные
промежутки с ограничением в 1/4 строки. Проверки ниже ранее подтверждали нашу
собственную сетку, **не совпадение с книгой**. Прежний visual sign-off отозван.

Новый алгоритм (`prepare` v5, KFGQPC v3, Tajweed v2) сохраняет исходные advances,
боковые выносы и метрику пробела. QCF V2 не содержит space glyph: никаких
придуманных пробелов не добавляется. Каждая строка целиком центрируется с учётом
и advance, и выходящего за него контура. Контуры не деформируются и слова между
строками не переносятся. Это **исправление шрифтовой раскладки**, не факсимиле.

QF19 p475 / 40:77 содержит составные записи: word 2012085 хранит два глифа,
а 2012086 — надстрочный знак с нулевым advance. Нельзя заменять ноль шириной ink
или объявлять слово отсутствующим по одной записи. Нулевая запись допускается
только при привязке к предшествующей положительной ячейке того же аята; знак
должен попадать в её горизонтальные границы. Отдельный regression test сравнивает
все контуры, координаты и CPAL-слои со shaping **всей исходной строки** целиком.

Hit cells следуют advances. Прямоугольники ink могут перекрываться из-за выносов
диакритики; ради устранения такого перекрытия нельзя двигать буквы. В подробностях
Flutter проверяет безопасную границу по пикселям; если отделить фрагмент нельзя,
показывает неизменённую страницу с выделением в прокручиваемом контексте.

Контрольные пакеты: `tmp/mushaf-source-metrics-20260908/{qcf,kfgqpc,tajweed}-samples`,
страницы 1, 2, 3, 50, 51, 604. Это новые локальные файлы, **не обновление staging**.
Старые offline-пакеты/опубликованные файлы не перезаписываются и не удаляются.
Не публиковать исправление как «в точности как в книге» по одному лишь прохождению
тестов. Для этого нужны оригинальные полные страницы конкретного издания либо
его точная исходная координатная раскладка вместе с оформлением и визуальная сверка.

Flutter больше не обрезает боковые поля Madani в landscape (убран bleed 1.12)
и не накладывает sepia multiply на бумагу и цветные Tajweed-глифы. Внешний фон
Madani белый, как опубликованный PDF-растр. Служебные название/джуз/номер сохранены:
контрольная страница 45 этого источника не содержит печатной рамки и номера.
Не приписывать источнику отсутствующие декоративные элементы. Масштабирование
остаётся равномерным.

## Прежняя сетка (история, не критерий книжной точности)

Это раскладка IQRO из закреплённых исходных контуров, а не факсимиле печати.
Разные шрифты не обязаны иметь одинаковые формы и длины слов. Не исправлять
разницу шрифтов горизонтальным сжатием букв, добавлением букв/огласовок или
переносом слов на другие строки.

## Правила

- Один равномерный масштаб всех слов аятов **на странице**. Общая базовая линия
  внутри каждой строки и постоянный шаг строк: 96 единиц canvas 1000×1600.
  Если QF требует отдельный заголовок над 15 исходными строками, 16 позиций
  равномерно занимают ту же область (шаг 90). Пустые исходные строки сохраняются.
- Размер текста ограничен общей высотой верхних/нижних элементов страницы и
  самой широкой строкой с зарезервированными пробелами. Это предотвращает
  пересечение диакритики соседних строк и «плавающие» базовые линии.
- Минимум 1/12 шага между строковыми ink bounds и столько же зарезервировано
  на каждый межсловный промежуток при выборе масштаба. Верхние/нижние границы
  строк не вычисляются заново для каждого аята.
- Межсловная разрядка ограничена четвертью шага строки, центрированные строки —
  одной восьмой. Неполная строка может заканчиваться раньше левого края:
  свободная бумага не превращается в чрезмерные пробелы.
- QCF сохраняет `is_centered` из согласованной базы. В QF 5 такого флага нет:
  центрируются начальные страницы и окончания сур, определённые по исходному
  терминальному номеру аята, а не по произвольному порогу ширины пробела.
- `validate_typography` останавливает подготовку при нарушении шага, размера,
  межсловных промежутков или выходе глифа из строки. Геометрия нажатия
  генерируется заново из тех же контуров; канонические ссылки не меняются.
- Flutter отображает полный растр одним равномерным преобразованием. Нет
  разрезания картинки на полосы, распределения лишней высоты между строками
  или масштабирования в зависимости от границ hit-map. Безопасная обрезка
  фрагмента для подробностей аята остаётся отдельной операцией.

## Проверка и выпуск

Контрольные страницы для обоих источников: **1, 2, 3, 50, 77, 255, 604**.
После визуальной проверки выполнить полный аудит 604 страниц обоих источников:

```bash
IQRO_MUSHAF_TYPOGRAPHY_FULL=1 \
IQRO_MUSHAF_FULL_SOURCE_DIR=/absolute/path/qcf-source \
IQRO_KFGQPC_SOURCE_DIR=/absolute/path/kfgqpc-source \
python3 -m unittest discover -s ops/mushaf-glyph-pilot -p test_typography.py
```

Все исходные версии/порядок слов, огласовки, canonical mappings и пропорции
контуров сохраняются. Для изображений дополнительно проверяются lossless pixels,
SHA, все три разрешения, mobile hit-testing и обновление offline-пакета.

Новые версии: `qcf-v2-iqro-20260908-v4` и `kfgqpc-iqro-20260908-v2`.
Нельзя перезаписывать файлы старых версий или подменять их изображения без
соответствующей карты аятов. Публикуется только полный проверенный пакет.
`build_full.py --pages ...` и `kfgqpc.py --pages ...` готовят контрольные страницы
**без** публикационного manifest. Факт публикации/установки фиксируется отдельно
в `clients/iqro_mobile/docs/PUBLIC_RELEASE_PLAN.md`.
