# Плашка Google Play на сайте

На сайте есть официальный значок «Доступно в Google Play». Он ведёт на страницу приложения:
`https://play.google.com/store/apps/details?id=forum.iqro.app` (открывается в новой вкладке).

## Где стоит

- **Главная** — блок «Мобильное приложение IQRO» под разделами, на телефоне и на компьютере. Блок
  стоит в потоке страницы: ничего не закрывает и не пересекается с пузырьком объявлений и
  мини-плеером.
- **Подвал** всех страниц — рядом с отметкой «Скоро для iOS». На телефоне подвал свёрнут в
  «Об IQRO и полезные ссылки».

На iPhone значок показывается так же: он лишь сообщает, что приложение есть в Google Play, и
ничего не обещает для iOS. Рядом в подвале остаётся «Скоро для iOS».

## Как включить

По умолчанию плашка выключена: пока Google не одобрил выпуск, страница в магазине не открывается.
Без ссылки в подвале остаётся прежняя отметка «Скоро для Android», блока на главной нет.

В день выхода, без нового кода:

1. В `.env.production` на сервере добавить строку
   `WEB_ANDROID_PLAY_STORE_URL=https://play.google.com/store/apps/details?id=forum.iqro.app`.
2. Пересобрать и перезапустить сайт (`make production-up`): адрес встраивается в образ web при
   сборке (→ `NEXT_PUBLIC_ANDROID_PLAY_STORE_URL`), как ID счётчиков статистики.

Чтобы выключить — убрать строку и пересобрать сайт.

## Значок

Файлы `services/web/public/images/store/google-play-{ru,en,ar,tr}.webp` — официальные значки
Google (`play.google.com/intl/en_us/badges`), по одному на язык сайта, без перерисовки: PNG
переведены в WebP без потерь, прозрачные края обрезаны. Свободное поле по правилам бренда
(четверть высоты значка с каждой стороны) задаёт CSS — класс `.google-play-badge`. Значок
нельзя перекрашивать, обрезать и менять в нём надпись.

Подпись для экранных читалок — `footer.googlePlayBadge` в `services/web/lib/messages/`.

## Тесты

- `services/web/lib/store-badge.test.ts` — без ссылки плашки нет; для каждого языка есть файл
  значка и подпись.
- `services/web/e2e/google-play-badge.spec.ts` — на главной и в подвале, на четырёх языках,
  верный адрес, новая вкладка; на телефоне блок стоит в потоке страницы.

Картинки для постов: [guides/google-play-badge](guides/google-play-badge/README.md).
