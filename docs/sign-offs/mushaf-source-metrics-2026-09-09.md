# Мусхафы: исправление метрик, проверка и доставка

Этот протокол отделяет техническую проверку от книжной точности. Точные формы,
порядок слов и исходные метрики сохранены; **совпадение всей композиции с печатным
оригиналом пока не подтверждено**. Прежний visual sign-off не восстановлен.

## Финальный статус этого этапа

**Все три версии из таблицы ниже опубликованы на staging и проверены через API/CDN.**
KFGQPC v3 также полностью обновлён на подключённом Redmi Note 7. QCF V2 v5 и
Tajweed v2 на этом устройстве целиком не переустанавливались: после обновления
KFGQPC осталось 708 MiB. Их новые пакеты доступны через «Проверить обновления»;
старый скачанный пакет не исчезает от одного лишь серверного переключения версии.
Полная device/offline-приёмка этих двух новых пакетов остаётся отдельным пунктом.
Ничего дополнительно ради места не удалялось.
