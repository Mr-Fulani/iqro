# Таджвид: отдельная проба оригинальных страниц

## Что проверяем

По запросу пользователя: показать на Android книжную страницу без новой
верстки и без растягивания по одной оси. Это **визуальная проба трёх страниц**,
не замена QCF V4 и не публикация нового 604-страничного издания.

Проба доступна только при `TAJWEED_BOOK_PREVIEW=true`, не в release mode и не
при `APP_ENV=production`. В обычной сборке маршрут и пункт меню не включены.
Открытие: Мусхаф → меню «…» → «Таджвид · проба книжной страницы».
Прямой маршрут тестовой сборки: `/mushaf/tajweed-book-preview`.

## Отображение

- Один полный source rectangle, единый пропорциональный масштаб.
- В исходниках печать присутствует у всех четырёх краёв: уменьшать поля здесь
  нельзя, иначе будет потеря рамки или цветовой легенды. Crop равен полной странице.
- «По ширине» не добавляет боковые поля внутри безопасной области экрана;
  при нехватке высоты доступна вертикальная прокрутка всей страницы.
- «Вся страница» сохраняет всю страницу одновременно, с неизбежными полями
  при несовпадении пропорций экрана и источника.
- Pinch zoom; двойной тап сбрасывает масштаб. Одиночный тап скрывает/показывает
  меню. Поворот сбрасывает translation/zoom, сохраняя декодированный кадр.
- Собственные заголовки/номера/рамки поверх печатного оригинала не добавляются.
  Управление — скрываемый overlay, оно не раздвигает строки.
- Свайпы страниц физически RTL в RU/EN/AR/TR; один haptic на смену страницы,
  с сохранением пользовательского выключателя отклика.

## Чего здесь намеренно нет

Нет выделения аятов, аудио от тапа и сохранения места чтения: у EasyQuran другая
раскладка, готовой проверенной карты этого источника нет. Геометрию QCF V4
использовать запрещено. Основная читалка, выбор издания, аудио, аватары, аккаунт,
каноническая БД и текущие загрузки не изменяются. Staging не обновляется.

645 px недостаточно для качественного увеличения на современном экране.
Увеличение изображения не превращает его в HD. До полноценного подключения нужны
высококачественный источник той же книги, точная карта аятов и проверка всего корпуса.

```sh
  test/features/mushaf_facsimile_test.dart \
  test/integration/tajweed_book_sample_test.dart

  --dart-define=APP_ENV=staging \
  --dart-define=API_BASE_URL=https://staging.iqro.forum \
  --dart-define=TAJWEED_BOOK_PREVIEW=true
```
