# Файл llms.txt для ботов нейросетей

`https://iqro.forum/llms.txt` — короткое описание сайта для нейросетей (ChatGPT, Claude,
Perplexity и других) по соглашению [llmstxt.org](https://llmstxt.org). По нему бот понимает, что
такое IQRO и какие страницы главные. Посетителю сайта файл не виден: ссылок на него на страницах
нет.

Доступ ботам открывает не этот файл, а `robots.txt` (`services/web/app/robots.ts`) — он уже
разрешает всем ботам всё, кроме входа, профиля, заметок, `/api/` и `/admin/`.

## Где лежит

`services/web/public/llms.txt` — обычный текстовый файл в разметке Markdown, на английском.
Сайт отдаёт его как есть; кода для него нет. Ссылки в нём полные, на `https://iqro.forum/en/...`.

## Как обновлять

Когда на сайте появляется новый публичный раздел (или раздел убирают):

1. Добавить или убрать строку в нужном разделе файла: `- [Название](полная ссылка): что там есть`.
2. Писать только то, что уже работает на сайте; ссылка должна открываться (код 200).
3. Не добавлять закрытые разделы: `/login`, `/register`, `/profile`, `/notes`, `/api/`,
   `/admin/` — это проверяет тест.
4. Возможности, которые есть только в приложении (например, проверка чтения вслух), так и
   помечать: «app only».

Изменение попадает на сайт с обычной выкладкой.

## Проверка

Тест «llms.txt describes the site for AI crawlers…» в `services/web/e2e/seo.spec.ts`: файл
отдаётся с кодом 200, как текст, начинается с `# IQRO` и не содержит закрытых разделов.
