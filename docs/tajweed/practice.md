# Таджвид, этап 4: практика

Практика закрепляет пройденные уроки курса «Таджвид» ([`course.md`](course.md)). Задания
собираются из разметки всего Корана по целям пройденных уроков. Ошибки возвращаются на
повторение через интервалы. Есть счёт и серия дней. Сайт и приложение работают одинаково,
результаты вошедших синхронизируются.

## Задания

| Тип (`type`) | Что видит ученик | Ответ |
|---|---|---|
| `find` | «Найдите в аяте: «{правило}»». Аят без подсветки, слова — кнопки | нажать слово; верно, если слово входит в любое место цели |
| `identify` | «Какое это правило?». В аяте нейтральным цветом выделено место `focus` | выбрать название из вариантов `options` |
| `listen` | «Послушайте и определите правило». Кнопка фрагмента (место `focus`), «0,75×»; аят скрыт до ответа | выбрать название из вариантов |

- Считается первый ответ. После него задание показывает правильный ответ: место цветом цели и
  «Верно!» или «Неверно. Здесь «{правило}»». Дальше идёт «Далее».
- Выделение в `identify` нейтральное (цвет акцента проекта), а не цвет правила: цвет подсказал бы
  ответ.
- У `listen` нет таймингов у чтеца → задание показывается как `identify`, и в результат пишется
  `identify`.
- Механика шагов та же, что в уроке: задания — шаги, «Назад» показывает прошлые задания с ответом,
  стрелки по направлению чтения, звук сбрасывается при смене шага.

## API

### `GET /api/v1/tajweed/courses/{slug}/practice`

Публичный, как примеры урока. Параметры:

| Параметр | Значение |
|---|---|
| `lessons` | пройденные уроки через запятую (до 30); цели берутся у них. Нет ни одного известного урока → 400 |
| `count` | число заданий, 1–12, по умолчанию 8 |
| `seed` | целое 0…2³¹−1; один и тот же `seed` даёт те же задания (для тестов) |
| `review` | до 6 ключей заданий на повторение через запятую: `{type}~{verse_key}~{target}` |

Ответ:

```json
{"seed": 42, "tasks": [
  {"key": "identify~112:4~idgham_wo_ghunnah", "type": "identify", "target": "idgham_wo_ghunnah",
   "review": false,
   "example": {"verse_key": "112:4", "surah_number": 112, "ayah_number": 4, "page_number": 604,
               "words": [{"position": 1, "text": "وَلَمْ"}, …],
               "occurrences": [{"parts": [{"position": 2, "start": 3, "end": 5},
                                          {"position": 3, "start": 0, "end": 1}]}]},
   "focus": 0,
   "options": ["qalaqah", "idgham_wo_ghunnah", "ikhafa"]}
]}
```

- `example` — того же вида, что примеры урока: все слова и все места цели.
- `focus` — индекс места, о котором спрашивают `identify` и `listen` (у `find` — 0).
- `options` есть у `identify` и `listen`: правильная цель и до трёх других целей пройденных уроков,
  перемешанные. Цель, место которой задевает те же буквы, в варианты не попадает: ответ должен
  быть один.
- Задания на повторение идут первыми (`review: true`). Ключ, который больше не собирается (аят без
  цели, цель не из пройденных уроков), пропускается.
- Остальные задания случайные:
  - цель выбирается равновероятно из пройденных;
  - аят — случайный из коротких (до 20 слов), где цель есть;
  - один аят с одной целью встречается в сессии один раз;
  - тип случайный; `find`, если пройдена только одна цель (вариантов для выбора нет).

### Результаты: `POST /api/v1/me/tajweed/practice-sessions`

Только для вошедших. Сессия практики отправляется после последнего ответа:

```json
{"id": "019a…", "course": "tajweed", "local_date": "2026-10-22",
 "finished_at": "2026-10-22T10:05:00.000Z",
 "answers": [{"key": "find~112:4~izhar", "target": "izhar", "type": "find",
              "correct": true, "at": "2026-10-22T10:01:00.000Z"}]}
```

- `id` создаёт клиент (UUID). Повтор с тем же телом → 200, с другим телом → 409, новый → 201.
- В сессии до 50 ответов.
- Ответ — состояние практики (см. ниже) после этой сессии.

### Состояние: `GET /api/v1/me/tajweed/practice/{course}`

```json
{"course": "tajweed", "sessions": 3, "answers": 24, "correct": 19, "score": 19,
 "streak": {"current": 2, "best": 4, "last_date": "2026-10-22"},
 "review": [{"key": "identify~2:2~idgham_wo_ghunnah", "target": "idgham_wo_ghunnah",
             "type": "identify", "box": 1, "due_at": "2026-10-22T10:03:00.000Z"}]}
```

Состояние не хранится, а считается из всех сессий ученика по порядку `finished_at`. Поэтому
телефон и браузер, отправляющие сессии в любом порядке, сходятся к одному результату.

## Счёт, серия, повторение

Одна функция на Python, TypeScript и Dart (`apply_session` / `applyPracticeSession`) применяет
сессию к состоянию:

- **Счёт** — число верных ответов.
- **Серия** — дни подряд с практикой, по `local_date` сессии:
  - тот же день — серия не меняется;
  - следующий день — +1;
  - пропуск — серия снова 1;
  - `best` — лучшая серия.

  Показывается `current`, если последний день — сегодня или вчера, иначе 0.
- **Повторение** (коробки Лейтнера) по ключу задания:
  - ошибка → коробка 1, задание ждёт сразу (`due_at` = время ответа);
  - верный ответ в коробке 1 → коробка 2 через 1 день;
  - верный ответ в коробке 2 → коробка 3 через 3 дня;
  - верный ответ в коробке 3 → задание выучено и уходит из списка;
  - верный ответ на задание не из списка ничего не меняет.

  Сессия берёт до 4 заданий, у которых подошёл срок (`due_at` ≤ сейчас), в порядке срока.

## Клиенты

- Сайт: `/{locale}/tajweed/practice`. Приложение: `/tajweed/practice`.
- Карточка «Практика» стоит на главной курса, а также после «Урок пройден».
- Экран начала:
  - счёт, серия, «На повторение: N»;
  - цели пройденных уроков (чипы с цветом);
  - «Начать практику».

  Без пройденных уроков — «Пройдите хотя бы один урок курса» и ссылка на курс.
- Сессия: 8 заданий, счётчик «Задание 1 из 8», live-регион с итогом ответа.
- Итог: «Верно X из Y», счёт, серия, «На повторение: N», «Ещё раз», «К курсу».
- Локально (`localStorage` / `app_state`, ключ `tajweed.practice.<course>`):

  ```json
  {"state": {…состояние как в API…}, "pending": [{…сессия…}]}
  ```

  - сессия применяется к `state` сразу и кладётся в `pending`;
  - у вошедшего `pending` отправляется по одной сессии (старые первыми), ответ сервера заменяет
    `state`, отправленные сессии уходят из `pending`;
  - при открытии практики вошедший без `pending` получает состояние `GET` и заменяет им своё;
  - `pending` хранит до 50 сессий, лишние старые отбрасываются.
- Доступность:
  - варианты — кнопки, выбранная — `aria-pressed`;
  - итог ответа объявляется;
  - всё помещается на 360 px.
