# Таджвид, этап 2: разбор аята по шагам

Ученик открывает аят и проходит его правила по одному, в порядке чтения. Сайт и приложение
работают одинаково. Данные те же, что на этапе 1:

- разметка правил по словам — `GET /api/v1/quran/tajweed/pages/{page}`;
- справочник правил — `GET /api/v1/quran/tajweed/rules`;
- тайминги слов чтеца — `GET /api/v1/recitations/{id}/ayahs/{s}/{a}`.

API бэкенда для разбора не менялся.

## Где открывается

- **Таджвидный Мусхаф** (QF Мусхаф 19):
  - сайт: нажатие на аят или его номер открывает меню аята под страницей, в нём кнопка
    «Разбор таджвида». В полноэкранной читалке на телефоне меню аята скрыто, поэтому кнопка
    «Разбор таджвида · 112:4» появляется над строкой чипов-легенды;
  - приложение: пункт «Разбор таджвида» в меню аята (долгое нажатие на аят или кнопка
    перевода внизу).
- **Цветной режим заучивания**: кнопка «Разбор таджвида» под легендой каждого аята.

Кнопка есть только у аята, в котором есть правила.

## Шаги

Шаги строит `tajweedSteps` (сайт — `services/web/lib/tajweed.ts`, приложение —
`lib/features/tajweed/tajweed_models.dart`):

- слова идут по `position`, правила внутри слова — в порядке разметки;
- каждое правило в каждом месте — отдельный шаг. Если в одном слове несколько правил, это
  несколько шагов;
- правило, которое переходит через границу слов (`joins_next` / `joins_previous`), — один шаг
  на оба слова. Шаг принадлежит первому слову;
- коды, которых нет в справочнике, пропускаются.

Пример, 112:4:
1. идгам без гунны «يَكُن لَّهُۥ»;
2. мадд табии · силя сугра «لَهُۥ»;
3. калькаля при остановке «أَحَدٌۢ».

После шагов идёт **итог** (`stepRules`). Это правила, которые встретились, в порядке первого
появления. Каждое правило открывает свою карточку: «Когда действует», «Как читать» и «Где в
этом аяте». Места в карточке подписаны «Шаг N» и ведут на свой шаг.

## Что на шаге

- **Аят глифами шрифта QCF V4.**
  - Слова шага подсвечены: фон цвета правила и подчёркивание.
  - Пока звучит весь аят, текущее слово выделено по таймингам.
  - Глифы для экранного диктора скрыты, слово шага он читает в карточке.
- **«Прослушать весь аят»** играет `[segment.start_ms, segment.end_ms)` трека суры.
- **Счётчик «1 из 3»** и полоса прогресса. Счётчик — live-регион: при смене шага диктор
  произносит «1 из 3: Идгам без гунны».
- **Карточка правила**: название (и вариант), арабское название, слово(а) с окрашенными
  буквами правила, «Почему здесь» и «Как читать» (у варианта — его тексты).
- **«Послушать фрагмент»** и переключатель «0,75×».
  - Фрагмент играет от начала первого слова шага до конца последнего (`stepTiming`).
  - Без таймингов кнопок нет.
  - Скорость общая для фрагментов и всего аята.
- **«Назад» / «Далее»**: на последнем шаге «Итог», на итоге «Готово» (закрывает разбор).
  Есть «Начать сначала».
- Пометка «Пояснения проходят проверку…», пока справочник не подписан преподавателем.

Чтец тот же, что у карточки этапа 1: в Мусхафе — чтец воспроизведения Мусхафа, в
заучивании — чтец плана.

## Механика шагов (общая с курсом намаза)

Разбор не пишет свою навигацию, а использует механику урока намаза. Курс намаза переведён на
те же части. Этапы 3 (курс «Таджвид») и 4 (практика) берут их же.

| | Сайт | Приложение |
|---|---|---|
| Текущий шаг и переход | `components/useStepNavigation.ts` | `IqroStepController` (`lib/core/design_system/iqro_step_flow.dart`) |
| Клавиши-стрелки по направлению чтения | `lib/step-navigation.ts` (`stepKeyDelta`) | `IqroStepPager` (`CallbackShortcuts`) |
| «Назад» / «Далее» / завершение | `components/StepNav.tsx` | `IqroStepButtons` |
| Действия «Следующий / Предыдущий шаг» для диктора | кнопки | `IqroStepPager` (`customSemanticsActions`) |
| Сброс звука при смене шага | эффект на индекс шага: `stop()` обоих плееров | `stopStandaloneOf(owner)` в `onPageChanged` |

Клавиши:
- в LTR «→» — вперёд, «←» — назад;
- в RTL наоборот;
- клавиши из полей ввода и медиаэлементов не перехватываются.

Звук на сайте:
- `components/TajweedAudio.tsx` — `useClipPlayer` играет отрезок трека и останавливается на его
  конце;
- захват фокуса через `lib/audio-focus.ts`: новый звук останавливает другие плееры;
- остановка во время загрузки не даёт клипу стартовать позже;
- следующее «Послушать» начинает отрезок с начала.

Звук в приложении: единственный `AudioController.loadStandalone` с `ClippingAudioSource`.
Позиция клипа считается от его начала. Поэтому текущее слово ищется по `clipStart + position`.

Оболочка листа общая с карточкой этапа 1: `TajweedDialog` в `components/TajweedParts.tsx`. Она
даёт `showModal`, нижнюю шторку на телефоне, Esc, закрытие по подложке и возврат фокуса.

## Доступность и языки

- Строки на 4 языках:
  - сайт: `tajweed.breakdown`, `playAyah`, `stepOf`, `stepNumber`, `previous`, `next`,
    `toSummary`, `done`, `summary`, `summaryTitle`, `restart`, `backToSummary`, `keyboardHint`;
  - приложение: `tajweedBreakdown…` в `app_*.arb`, плюс `tajweedNextStep` и
    `tajweedPreviousStep`.
- Лист открывается с фокусом на заголовке. На сайте: Esc и «×» закрывают лист, фокус
  возвращается на кнопку, которая его открыла. В приложении — `showModalBottomSheet`.
- Арабский текст всегда RTL, раскладка на логических отступах.
- Анимации подсветки отключаются при `prefers-reduced-motion` (сайт) и `disableAnimations`
  (приложение).
