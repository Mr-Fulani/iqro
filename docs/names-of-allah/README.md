# Имена Аллаха

Раздел «Имена Аллаха»: колесо из имён и карточка каждого имени — арабское написание, имя буквами
языка интерфейса, значение, толкование, ссылка на аят и запись слова чтецом. Одинаково на сайте и в
приложении, на четырёх языках (ru, en, tr, ar).

Одобренный владельцем прототип колеса — [prototype.html](prototype.html) (12.11.2026). Решения
владельца, которые его меняют:

1. Нажатие в центр колеса переходит к следующему имени (щелчок и вибрация); вращение пальцем
   остаётся; карточку открывает нажатие на блок под колесом (имя, транслитерация, значение).
2. Оформление — тема сайта и приложения, светлая и тёмная; форма колеса, деления и стрелка — как в
   прототипе.
3. Подписи на колесе переключаются «язык интерфейса / арабский»; блока «Языки карточки» нет.
4. Содержание — из книг: список и порядок имён — Са‘ид аль-Кахтани, «Шарх асма Аллах аль-хусна»;
   толкование — ‘Абд ар-Рахман ас-Са‘ди. Не список из хадиса ат-Тирмизи, который стоит в прототипе.
   Карточка называет книгу-источник.
5. Звук. Сначала решили брать запись чтеца — слово аята, как «Прослушать слово» в Мусхафе. На
   телефоне она запаздывала, и 12.11.2026 владелец дал свои записи имён: теперь имя звучит из
   записи, вложенной в сайт и приложение, а чтец остался запасным вариантом (раздел «Звук» ниже).
6. «Пройдено» и «выучено» хранятся на устройстве у гостя и в аккаунте у вошедшего
   (`LearnerProgressKind`, см. [courses/README.md](../courses/README.md), «Прогресс в аккаунте»).

## Сервер

Модуль `quran_backend.modules.names`, свои таблицы (общей таблицы «религиозного содержания» нет):

| Таблица | Что хранит |
| --- | --- |
| `names_collection` | Список (`asma-al-husna`) и его действующая версия |
| `names_version` | Версия: статус, подпись владельца, книги-источники на четырёх языках |
| `names_name` | Имя в версии: номер, код, арабский текст, тексты карточки, аят, слово |
| `names_document` | Готовый ответ API: одна строка на версию и язык |

Версии устроены как у курса намаза и ду‘а: черновик → подпись владельца → публикация. Подписанная и
опубликованная версии не меняются; исправление — новый черновик-копия. При публикации прежняя версия
получает статус «Отозвана», сайту уходит событие `names.collection.changed`, в Telegram — оповещение.

Поля имени (`names.DivineName`):

- `position` — номер в списке, подряд с 1; `slug` — код латиницей (`ar-rahman`). По коду клиенты
  хранят отметки «пройдено» и «выучено», поэтому у имени он не меняется от версии к версии.
- `arabic` — имя с огласовками.
- `transliteration_{ru,en,tr}` — имя буквами языка. Арабского нет: в арабском интерфейсе показано
  само имя.
- `meaning_{ru,en,tr,ar}`, `tafsir_{ru,en,tr,ar}` — значение и толкование.
- `tafsir_ref` — необязательное место в книге (страница или аят), показывается после названия книги.
- `tafsir_source_{ru,en,tr,ar}` — заполняется, только если толкование этого имени взято не из книги,
  указанной у версии (на всех четырёх языках сразу). В ответе API у каждого имени есть готовое
  `tafsir_source`: своя книга имени или книга версии.
- `surah`, `ayah` — аят для «В Коране»; пусто, если имени в Коране нет (имя из Сунны).
- `word_position` — номер слова в аяте для «Слушать»; пусто — кнопки нет.

Подписать можно только полную версию (`publication.version_problems`): источники списка и толкования
на всех языках, у каждого имени — транслитерация на трёх языках, значение и толкование на четырёх,
номера подряд. Число имён сервер не задаёт: оно определяется книгой.

### API

`GET /api/v1/names/collections/{slug}?language=ru|en|tr|ar` — действующая опубликованная версия на
одном языке. Публичный, без авторизации, с `ETag` и `Cache-Control: public` (как курс намаза).
`404`, пока ничего не опубликовано: клиент показывает «Раздел готовится».

```json
{
  "collection": {
    "slug": "asma-al-husna",
    "version": "2026-11-12",
    "language": "ru",
    "published_at": "2026-11-12T10:00:00+00:00",
    "list_source": "Са‘ид аль-Кахтани. Шарх асма Аллах аль-хусна",
    "tafsir_source": "‘Абд ар-Рахман ас-Са‘ди. Тайсир аль-Карим ар-Рахман"
  },
  "names": [
    {
      "slug": "ar-rahman",
      "position": 1,
      "arabic": "الرَّحْمَٰنُ",
      "transliteration": "Ар-Рахман",
      "meaning": "Милостивый",
      "tafsir": "…",
      "tafsir_source": "‘Абд ар-Рахман ас-Са‘ди. Тайсир аль-Карим ар-Рахман",
      "tafsir_ref": "",
      "ayah": { "surah": 55, "ayah": 1, "word": 1 }
    }
  ]
}
```

`ayah` — `null`, если имени нет в Коране; `ayah.word` — `null`, если имя не одно слово аята.
`transliteration` в арабском документе — пустая строка.

### Загрузка содержания

`manage.py import_names [файл]` создаёт черновик из файла данных (по умолчанию
`modules/names/data/asma-al-husna.json`). Версию с тем же именем команда не трогает: правки владельца
в админке сохраняются. Формат файла:

```json
{
  "schema_version": 1,
  "collection": { "slug": "asma-al-husna", "version": "2026-11-12" },
  "list_source": { "ru": "…", "en": "…", "tr": "…", "ar": "…" },
  "tafsir_source": { "ru": "…", "en": "…", "tr": "…", "ar": "…" },
  "names": [
    {
      "slug": "ar-rahman",
      "arabic": "الرَّحْمَٰنُ",
      "transliteration": { "ru": "Ар-Рахман", "en": "Ar-Rahman", "tr": "er-Rahmân" },
      "meaning": { "ru": "…", "en": "…", "tr": "…", "ar": "…" },
      "tafsir": { "ru": "…", "en": "…", "tr": "…", "ar": "…" },
      "tafsir_source": { "ru": "", "en": "", "tr": "", "ar": "" },
      "tafsir_ref": "",
      "ayah": { "surah": 55, "ayah": 1, "word": 1 }
    }
  ]
}
```

Номер имени — его место в списке `names`. Команда ничего не публикует: публикует владелец.

## Админка

Раздел «Обучение»:

- «Имена Аллаха: версии» — список версий. На странице версии: книги-источники (правятся в
  неподписанном черновике), «Что осталось заполнить» и «Список для проверки» — все карточки
  по-русски на одной странице, чтобы прочитать перед подписью. Действия над отмеченными версиями:
  «Подписать: религиозная проверка пройдена», «Опубликовать», «Создать черновик-копию для правок»
  (имя новой версии — сегодняшняя дата).
- «Имена Аллаха» — имена версии, над которой идёт работа (черновик, а если его нет — действующая).
  Имя правится на своей странице: блоки по языкам и «В Коране и звук». В подписанной и
  опубликованной версии имена только читаются.
- На главной, «Требует внимания»: «Имена Аллаха: черновики ждут подписи» и «…подписано, не
  опубликовано».

Права стандартные (`names.change_namesversion`, `names.change_divinename` и т. д.).

## Сайт

Страница `/{locale}/names` (`app/[locale]/names`), пункт «Имена Аллаха» в верхнем меню, в «Ещё» на
телефоне и в подвале. Пример ответа API, общий для сайта, приложения и тестов, —
[names-document.example.json](names-document.example.json).

- `components/names/NamesWheel.tsx` — колесо на canvas: подписи с лупой у стрелки, деления каждые
  11 и 33 (как у тасбиха), инерция и доводка до имени. Цвета и шрифты берутся из переменных темы
  сайта (`--panel`, `--primary`, `--accent-gold`, `--font-sans`, `--font-arabic`), поэтому на
  телефоне колесо получает тёплую палитру мобильной вёрстки. Отдельной тёмной темы у сайта нет —
  нет её и у колеса.
- Управление: вращение пальцем или мышью; стрелки на клавиатуре; нажатие в центр — следующее имя;
  блок под колесом (имя, транслитерация, значение) открывает карточку, как и Enter на колесе.
- Щелчок — короткий звук Web Audio и `navigator.vibrate(4)`; переключатель «Звук» выключает и
  щелчок, и чтеца. При `prefers-reduced-motion` колесо переходит к имени без анимации.
- Подписи: «язык интерфейса / عربي». С арабскими подписями колесо идёт в обратную сторону, как
  письмо. В арабском интерфейсе переключателя нет.
- Когда стрелка остановилась на имени, оно считается пройденным, и (при включённом звуке) чтец
  произносит его.
- Звук — `components/names/use-name-voice.ts`: слово `ayah.word` аята из дорожки суры по пословным
  таймингам, тем же способом, что «Прослушать слово» в Мусхафе. Голоса по порядку: учебный
  аль-Хусари, затем чтецы с пословными таймингами (`wordTimingFallbackRecitations`). Нет `ayah.word`
  — нет кнопки «Слушать».
- Карточка (`NameCard.tsx`) — нижний лист на телефоне, окно на компьютере: каллиграфия, «Слушать»,
  «Выучено», толкование с названием книги (`name.tafsir_source` и `tafsir_ref`), «В Коране» —
  ссылка `/quran?surah=&ayah=` в наш читатель, книга списка, «Предыдущее / Следующее».
- Отметки — `localStorage`, ключ `names.progress.asma-al-husna`, формат прогресса курсов
  (`lib/course-progress.ts`): запись имени со `status: "in_progress"` — пройдено, `"completed"` —
  выучено. Счётчик «Пройдено N из M» считает имена текущего списка, у которых есть запись;
  «Выучено» — отдельная отметка, её можно снять.
- Пока владелец не опубликовал первую версию (API отвечает 404), страница показывает «Раздел
  готовится» и закрыта от индексации.
- Публикация версии обновляет страницу сразу: событие `names.collection.changed`
  (`lib/content-revalidation.ts`).
- Тесты: `lib/names.test.ts`, `e2e/names.spec.ts`.

## Приложение

Экран `/names` (`lib/features/names/`), карточка «Имена Аллаха» в «Ещё» стала рабочей.

- `names_wheel.dart` — то же колесо на `CustomPainter`: та же геометрия, лупа, деления, инерция и
  доводка, что на сайте. Цвета — из темы приложения (`colorScheme`, `iqroColors`), светлой и тёмной;
  арабские подписи — шрифтом «Amiri Quran». Колесо забирает касание сразу, поэтому страница под ним
  не прокручивается, пока его крутят. При отключённых анимациях переходит к имени без движения.
- Управление то же: палец крутит, нажатие в центр — следующее имя, карточка под колесом открывает
  лист имени (`name_card_sheet.dart`). Для экранного диктора колесо — ползунок со следующим и
  предыдущим именем.
- Щелчок — короткий звук `assets/sounds/names_tick.wav` (три проигрывателя по очереди, вне
  аудиосессии: щелчок не прерывает чтение Корана) и `HapticFeedback.selectionClick`. «Звук» выключает
  щелчок и чтеца; вибрация остаётся.
- Чтец — `NamesVoice` (`names_sound.dart`): слово аята через общий плеер (`loadStandalone` с
  границами слова), голоса по порядку — учебный аль-Хусари, затем чтецы с пословными таймингами.
- «В Коране» открывает `/reader/<сура>?ayah=<аят>`.
- Офлайн: `NamesRepository` сначала спрашивает сервер и кладёт ответ в кэш (`names:<список>:<язык>`,
  30 дней); без сети показывает последнюю копию. 404 (ничего не опубликовано) — «Раздел готовится»,
  копия при этом не показывается.
- Отметки — `app_state`, ключ `names.progress.asma-al-husna`, тот же формат, что на сайте
  (`CourseProgressStore` с `kind: 'names'`).
- Тесты: `test/features/names_models_test.dart`, `names_repository_test.dart`,
  `names_screen_test.dart` (нажатие в центр, вращение пальцем, карточка, отметки, звук выключен,
  арабский интерфейс, маленький экран с крупным шрифтом в обеих темах).

## Прогресс

У гостя отметки остаются на устройстве. У вошедшего в аккаунт они хранятся и на сервере — тем же
способом, что прогресс курсов ([courses/README.md](../courses/README.md), «Прогресс в аккаунте»):
`PUT /api/v1/me/courses/progress/names/asma-al-husna`.

- Имя — это «урок» с ключом `slug`: `in_progress` — стрелка останавливалась на имени («пройдено»),
  `completed` — «выучено». Более поздняя запись побеждает, поэтому снятая отметка «Выучено» не
  возвращается с другого устройства.
- Сайт (`useAccountProgressSync("names", …)` в `NamesWheel`) и приложение
  (`AccountProgressSync.names`) отправляют отметки при открытии раздела, после «Выучено» и при
  закрытии карточки, и сохраняют у себя слитый ответ. Офлайн и ошибки молчат: отметки уйдут в
  следующий раз.
- Сервер принимает отметки только опубликованного списка (`courses.progress.course_exists`).
- Админка, «Обучение → Ученики курсов»: строка «Имена Аллаха» у ученика и значение фильтра
  `?course=names`. «Пройдено X из N» в этой таблице — имена, отмеченные выученными, «Начато» —
  имена, на которых останавливалась стрелка; N — число имён действующего списка.

## Звук

Имена произносит запись владельца (три файла, по 33 имени: название и короткое пояснение
по-английски). Из каждой записи вырезано только само имя — без пояснения, поэтому один и тот же
звук подходит для всех языков. Файлы лежат по коду имени:

- сайт — `services/web/public/names-audio/<slug>.mp3`, список кодов — `lib/names-audio.ts`;
- приложение — `clients/iqro_mobile/assets/names_audio/<slug>.mp3` (читаются из списка ресурсов).

Запись вложена в сайт и приложение, поэтому звучит сразу и работает без сети. В приложении у неё
свой проигрыватель вне аудиосессии; когда стрелка останавливается на имени, а в это время играет
Коран, имя не произносится (кнопка «Слушать» в карточке работает всегда).

Как решается, что звучит по «Слушать» и при остановке стрелки:

1. есть запись имени — звучит она;
2. записи нет, но имя — одно слово аята (`ayah.word`) — его произносит чтец Корана;
3. нет ни того, ни другого — кнопки «Слушать» нет.
