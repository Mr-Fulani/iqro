# Схематичная 3D-иллюстрация намаза

Дополнение к картинкам курса «Обучение намазу». Курс (шаги, иллюстрации, тексты, аудио) не меняется: у шага появляется переключатель «Картинка / 3D», по умолчанию — картинка. Сайт и приложение ведут себя одинаково.

## Откуда сцена

Прототип владельца `salah3d.zip` (21.10.2026, сцена версии 0.1.0): персонаж собран кодом из примитивов, карандашный шейдер, автоматическая камера, позы `qiyam`, `takbir`, `ruku`, `itidal`, `sujud`, `jalsa`, `sujud2`, `tashahhud`, `salam`. Сетевых запросов, `eval` и внешних адресов в коде нет. **Позы — черновик автора**, их проверяют вместе с курсом (ниже — что заметно при сверке с картинками).

| Где | Что |
|---|---|
| `services/web/lib/salah3d/salah-scene.js` | сцена автора как ES-модуль; `three` из npm, версия закреплена (`0.149.0` = r149 прототипа) |
| `services/web/lib/salah-3d.ts` | какой шаг курса какой позе соответствует (в приложении — `salah_3d.dart`) |
| `services/web/components/SalahStep3D.tsx`, `Salah3DStage.tsx` | выбор «3D» и холст; модуль с three.js грузится `next/dynamic` только по нажатию |
| `clients/iqro_mobile/assets/salah3d/` | офлайн-страница для WebView: `index.html` и мост `salah-embed.js` правятся руками, `salah-scene.js`, `three.min.js`, `LICENSE-three.txt` генерирует `npm run salah3d:app-assets` (из `services/web`); `lib/salah-3d.test.ts` падает, если копия устарела |
| `clients/iqro_mobile/lib/features/salah/salah_3d.dart` | WebView (`webview_flutter`), мост `SalahBridge`, состояние выбора |

Технические правки сцены (позы не тронуты): импорт/экспорт модуля вместо `window.THREE`/`window.SalahScene`; `SEGMENTS` и `setStep(id)` — показ движения одного шага по кругу (0,6 с предыдущей позы, переход, удержание); на паузе фигуру можно поворачивать; опция `pageScroll` (вертикальный свайп и колесо листают страницу, поворот — горизонтально, масштаб — щипком); `forceContextLoss` при `dispose`.

## Какой шаг получает 3D

`position` шага → поза сцены: `qiyam`, `takbir`, `ruku`, `itidal`, `sujud`, `jalsa`, `tashahhud` — одноимённые, `taslim` → `salam`. Суджуд сразу после джальсы → `sujud2` (движение из сидения). Без 3D: шаги без картинки, `qunut`, `tawarruk`, вуду и таслим после сидения таваррук (в сцене таслим — из ифтираша).

Поведение: 3D предлагается только при WebGL и без «уменьшения движения»; ошибка (нет WebGL, не загрузился модуль, потерян контекст) возвращает картинку до конца визита с пояснением. Выбор действует, пока открыт урок. Пауза при скрытой вкладке или приложении в фоне, освобождение при уходе из урока. Подписи и описание берутся из курса (4 языка, RTL для ar): холст скрыт от экранного диктора, описанием остаётся `alt` картинки; под сценой — «Схематичная 3D-иллюстрация», пауза, скорость 1/0,75/0,5, исходный ракурс.

Мост приложения: страница шлёт `LOADED` (скрипты и WebGL есть), `READY` (первый кадр шага), `STEP_CHANGED`, `ERROR` (`NO_WEBGL`, `SCRIPTS_NOT_LOADED`, `MOUNT_FAILED`, `CONTEXT_LOST`); приложение вызывает `salah.show(step, speed)`, `play`, `pause`, `setSpeed`, `resetCamera`, `dispose`.

## На проверку вместе с курсом

1. И'тидаль: в сцене после руку' руки снова сложены (поза `qiyam`), на картинке курса опущены — см. п. 6 `fiqh-review.md`.
2. Таслим в сцене — из ифтираша; после таваррука 3D не показывается, пока у сцены нет такой позы.
3. Ташаххуд: указательный палец поднимается дважды за цикл, камера приближает кисть.
4. Персонаж, одежда и куфия — набросок; для продакшна нужна модель художника.

## Как заменить персонажа на GLB

1. Модель с гуманоидным скелетом в glTF 2.0 (`.glb`, до ~1–2 МБ), позы или клипы под id из `STEPS`. Сжатие Draco/Meshopt потребует положить декодер рядом.
2. Загрузка — `GLTFLoader` из `three/examples/jsm/loaders/GLTFLoader.js` той же версии `three`. В r149 нет классических `examples/js`, поэтому генератор ассетов приложения должен будет собирать сцену бандлером (например, esbuild в IIFE) вместо простой обёртки.
3. В `salah-scene.js` заменить `Rig` (процедурная сборка, IK в `solve`) на скелет: `getPose(name)` → поза/клип, `rig.apply(pose)` → кости или `AnimationMixer.setTime`. Таймлайн `MAIN`, `SEGMENTS`, камера и тени остаются; им нужны точки `rig.J` (таз, грудь, голова, колени, стопы, кисти) — заполнять из мировых позиций костей.
4. Карандашный вид: `hatchMat` на меши модели (для SkinnedMesh — шейдерные чанки `skinning`) или `MeshToonMaterial`.
5. Файл модели: на сайте — статикой рядом с модулем, загрузка только после выбора «3D»; в приложении — в `assets/salah3d/`. Затем `npm run salah3d:app-assets` и повторная проверка поз.
