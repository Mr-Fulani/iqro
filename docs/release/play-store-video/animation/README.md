# Анимационный ролик IQRO (motion design)

Ролик около 57 секунд под озвучку из [README ролика](../README.md): сцены нарисованы с нуля в цветах и
шрифтах приложения, экраны приложения вставлены только в сцене «А ещё» (Мусхаф с цветным таджвидом,
перевод, тафсир и чтецы).

Готовые файлы — прямо в `~/Downloads/` (в git не кладутся):

- `iqro-promo-vertical.mp4` — 1080×1920, для Reels, Shorts и сторис;
- `iqro-promo-horizontal.mp4` — 1920×1080, для YouTube и страницы в Google Play: текст слева, картинка справа;
- `iqro-promo-*-storyboard.jpg` — раскадровка, кадр каждые 1,5 секунды.

Озвучка — вторая версия владельца от 22.11.2026 (ElevenLabs, «Stanislav», арабские слова произнесены
по-русски, 53,55 с); рабочая копия — `~/Downloads/iqro-video/voice-2026-11-22T10_28.mp3`. Титры повторяют
только слова озвучки.

H.264, 30 кадров/с, звук AAC 48 кГц, голос выровнен до −16 LUFS. Музыки нет.

## Английская версия

`~/Downloads/iqro-promo-vertical-en.mp4` и `~/Downloads/iqro-promo-horizontal-en.mp4` — та же анимация с
английскими надписями. Озвучка владельца от 22.11.2026 (53,63 с), рабочая копия —
`~/Downloads/iqro-video/voice-en-2026-11-22T11_54.mp3`. Тайминги — в `timing-en.json` (`"lang": "en"`):

```bash
python3 docs/release/play-store-video/animation/build.py --timing docs/release/play-store-video/animation/timing-en.json
```

Надписи на английском — в словаре `EN` в `index.html`; строки интерфейса (подсказка «A word was left out.
Read it», «Daily goal», «After-prayer reading», «Credited today», названия курсов и намазов) взяты из
`clients/iqro_mobile/lib/l10n/app_en.arb`, уведомление — из `notification_gateway.dart`. Снимки экранов —
из `../../play-store-screenshots/en/`; английского кадра с тафсиром нет, поэтому в телефоне два экрана
(Мусхаф и перевод), тафсир и чтецы — пунктами списка. `chips` в тайминге — когда загораются
«Word / Letter / Vowel» (доля длины фразы 3). Английский значок Google Play — с сайта.

## Как собрать

Нужны `ffmpeg`, Python-пакет `playwright` и Google Chrome.

```bash
python3 docs/release/play-store-video/animation/build.py
```

Оба формата собираются примерно за 10 минут. Куда и под каким именем: `--out` (папка) и `--name`. Только один формат: `--format 9x16` или `--format 16x9`.
Проверить отдельные кадры без сборки видео: `--stills 5,12.5,40 --out /tmp/kadry`.

## Как заменить голос

Текст озвучки тот же, меняется только файл. Все времена сцен — в одном файле `timing.json`:

- `voice` — путь к файлу озвучки;
- `cues` — секунда, с которой в **файле озвучки** начинается каждая фраза (номера — как в
  [сценарии](../README.md)); `3b` — «Прямо на телефоне…», `5b` — «IQRO напомнит…», `5c` — «Пять-десять минут…»,
  `7a2` — «Время намаза и кибла…», `7b2` — «Курс намаза…», `7b3` — «и курс таджвида…» (у этой фразы пауза
  короткая — искать с `d=0.12`);
- `voice_offset` — тишина перед голосом в начале ролика, `tail` — сколько секунд держать финал после голоса.

Начала фраз удобно найти по паузам:

```bash
ffmpeg -i новый-голос.mp3 -af silencedetect=n=-40dB:d=0.3 -f null - 2>&1 | grep silence_end
```

Затем скопировать `timing.json`, вписать новые секунды и собрать:

```bash
python3 docs/release/play-store-video/animation/build.py --voice ~/Downloads/новый-голос.mp3 --timing мои-тайминги.json
```

Длина ролика считается сама: длина голоса + `voice_offset` + `tail`. Движение внутри сцены привязано к
началу и длине фразы, поэтому подстраивается под более быстрый или медленный голос.

## Из чего сделано

- `index.html` — все сцены; кадр рисует функция `render(t)`, CSS-анимаций нет, поэтому каждый кадр
  считается точно. Открывается и в обычном браузере (пустой до вызова `setup`).
- `build.py` — открывает страницу в Chrome через Playwright, снимает кадры в несколько процессов,
  склеивает их `ffmpeg` с голосом и делает раскадровку.
- `assets/fatiha.json` — аяты 1–3 «Аль-Фатихи», взяты из API приложения
  (`/api/v1/quran/editions/madani-hafs/surahs/1/ayahs`, текст Tanzil). Арабский текст в ролике
  берётся только отсюда, слова целиком; шрифт Amiri Quran из приложения.
- `assets/reader-tafsir.jpg` — кадр записи `3-reader-tafsir-reciter.mp4` (19-я секунда): чтец, перевод, тафсир.
- Из репозитория берутся: имена Аллаха (`services/backend/.../names/data/asma-al-husna.json`), печать и
  значок IQRO, официальный значок Google Play с сайта, картинки пальмы из плана, снимки экранов
  `../../play-store-screenshots/ru/`.

## Что показано и почему это правда

Сверка фраз — в [README ролика](../README.md). В самой анимации:

- Проверка чтения: плашка идёт по словам, на пропущенном «ٱلْحَمْدُ» краснеет, внизу подсказка
  приложения «Слово пропущено. Прочитайте его», потом снова золотая — как на записи `n3-stop-hint-return.mp4`.
  Буквы и огласовки в тексте аята не искажаются: виды ошибок показаны только словами «Слово · Буква · Огласовка».
- Дневная цель в минутах / страницах / аятах, отметки «Чтение после намаза» для пяти намазов,
  уведомление с текстом из приложения («Время намаза» — «Наступило время молитвы: Зухр»), календарь
  прогресса и пальма, «Сегодня засчитано».
- Колесо 99 имён — первые имена в порядке приложения; кибла и время пяти намазов (время — со снимка
  экрана, Стамбул, 22 ноября).
- Курсы «Обучение намазу» и «Таджвид» с подписями из приложения.

Нет слов «точно», «без ошибок», оценок, наград и цен; нет людей и живых существ.
