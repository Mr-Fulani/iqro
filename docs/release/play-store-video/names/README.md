# Shorts «99 имён Аллаха» на русском

Три вертикальных ролика 1080×1920 для канала @iqro_ru — русская пара английских Shorts
«The 99 Names of Allah — Part 1–3» с основного канала. Оформление то же (тёмный циферблат, латунная
шкала, имя у стрелки, внизу арабское имя, транслитерация и значение). Отличия от английских:

- список и порядок — как в приложении (Са‘ид аль-Кахтани, с «Аль-Авваль»), а не ат-Тирмизи:
  русская озвучка владельца записана под этот список, решение владельца 23.11.2026;
- в центре колеса — орнамент вместо фигурки человека;
- в конце только Google Play (в App Store приложения нет).

Готовые файлы (в git не кладутся): `~/Downloads/iqro-names-ru-part1.mp4` (1:58),
`part2.mp4` (2:00), `part3.mp4` (2:05) и раскадровки `*-storyboard.jpg`. Музыки нет, голос — записи
владельца из `clients/iqro_mobile/assets/names_audio/ru`, выровнены до −16 LUFS.

## Как собрать

```bash
python3 docs/release/play-store-video/names/build.py            # все три части
python3 docs/release/play-store-video/names/build.py --part 2   # одна часть
```

Тексты — из `services/backend/.../names/data/asma-al-husna.json` (арабское имя, транслитерация и значение
по-русски). Каждое имя держится на экране столько, сколько звучит запись, плюс пауза
(`LEAD`, `GAP`, `MIN_SLOT` в `build.py`).
