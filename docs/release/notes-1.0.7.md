# IQRO 1.0.7 (код сборки 8): «Что нового» для Google Play

Вставляется в поле «Описание выпуска» Play Console целиком, с языковыми метками.

```
<ru-RU>
• Строка обновления в «Ещё»: остаётся там и после «Позже», обновиться можно в любой момент
• Предложение обновиться больше не пропадает, если закрыть и снова открыть приложение
</ru-RU>
<en-US>
• Update row in More: it stays there after "Later", so you can update any time
• The update offer no longer disappears when you close and reopen the app
</en-US>
<ar>
• سطر التحديث في «المزيد»: يبقى هناك بعد «لاحقًا»، فيمكنك التحديث في أي وقت
• لم يعد عرض التحديث يختفي عند إغلاق التطبيق وفتحه من جديد
</ar>
<tr-TR>
• "Daha" ekranında güncelleme satırı: "Daha sonra"dan sonra da orada kalır, istediğiniz zaman güncelleyin
• Uygulamayı kapatıp yeniden açınca güncelleme teklifi artık kaybolmuyor
</tr-TR>
```
