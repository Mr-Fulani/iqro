# Страница приложения в App Store

Тексты для App Store Connect → приложение → версия iOS и App Information. Основной язык —
русский, локализации — английский (США), арабский, турецкий. Описание то же, что в
[google-play-listing.md](google-play-listing.md), без «Продолжить с Google»: на iOS этого входа
нет (см. [app-store.md](app-store.md), раздел 8). Остальные поля — свои для App Store.

Лимиты App Store Connect: Name и Subtitle — до 30 знаков, Promotional Text — до 170,
Description — до 4000, Keywords — до 100 (держим до 100 байт в UTF-8 на случай подсчёта
в байтах; слова через запятую без пробелов, слова из названия и подзаголовка не повторяем).
Promotional Text можно менять без новой версии. Длины проверены скриптом 06.11.2026;
при правке проверяйте снова.

Нельзя: упоминать Android и другие платформы, цены, «лучший» и «№1», чужие названия
приложений в ключевых словах (правило 2.3).

IQRO is a calm place to read and study the Quran every day.

PRAYER AND CALENDAR

• Prayer reminders
• Hijri calendar

COURSES
• "Learning Salah" — step by step: wudu and the five prayers
• "Tajweed" — reading rules with examples from the Quran
• Thematic courses with video, notes and sources

DU'A
• Daily du'a and adhkar by topic, based on Hisn al-Muslim
• Arabic text, transliteration and meaning

LANGUAGES AND DATA
• Interface in English, Russian, Arabic and Turkish
• Everything works without an account; sign-in by email code is only for syncing devices
• No ads. Usage statistics only with your consent
