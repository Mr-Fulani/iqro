| Что | Файлы | Размер |

«Всё для ежедневной практики» — и их переводы.

## Откуда снимки

Экраны в `src/` — настоящие экраны приложения, отрисованные его тестами (без телефона):

```bash
cd clients/iqro_mobile
flutter test test/features/home_screenshots_test.dart --plain-name "store:" --dart-define=SCREENSHOT_DIR=/путь
flutter test test/features/course_screenshots_test.dart --plain-name "catalog with the site covers" --dart-define=SCREENSHOT_DIR=/путь
```

Картинки с подписью и рамкой собирает `python3 docs/release/store-graphics/make.py` (нужны
Python-пакет `playwright` и установленный Chrome).

Обложки курсов «Обучение намазу» и «Таджвид» — `docs/courses/covers/` (загружены на сайт 11.11.2026).

## Чего не хватает

- Снимков Мусхафа, плеера и времени намаза: тесты их без настоящих данных не рисуют, нужен телефон
  с приложением на каждом из четырёх языков. Play принимает от 2 до 8 снимков на язык, так что
  три уже годятся для первой загрузки.
- У значка прозрачные углы (печать на прозрачном фоне); Play сам обрежет его по своей маске.
