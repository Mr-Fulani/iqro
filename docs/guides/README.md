# Как пользоваться IQRO: картинки-инструкции

Картинки для постов пользователям: в каждой папке — PNG 1080×1350 (формат 4:5 для Telegram и Instagram) и `README.md` с подписью к каждой картинке. Подписи можно брать в пост как есть.

Материалы для онбординга, постов и рекламы в соцсетях. У каждой функции своя папка:

- `*.png` в корне папки — карточки 1080×1350 для постов;
- `reels/` — кадры 9:16 (1080×1920) для рилс, Shorts и сторис: обложка, по кадру на экран, финальный кадр;
- `screens/` — чистые экраны телефона без отметок, в полном размере, для своих анимаций;
- `video/` — записи экрана телефона без звука (MP4, H.264);
- `README.md` — подписи к карточкам и заголовок для ролика.

Папки `reels/`, `screens/` и `video/` есть у функций, переснятых с 09.11.2026; остальные дополняются.

## Как сделать инструкцию для новой функции

1. Снимите экраны: сайт с телефона (390×844), сайт с компьютера и приложение. Снимки, которые берёте не из `docs/images/`, положите в `<папка>/src/` (телефон — до 585 px в ширину, JPEG).
2. Опишите карточки в `<папка>/guide.json` — по образцу любой папки. На карточке: `title`, `platform` (`app`, `site-phone`, `site-desktop`, `both`), один или два снимка в `shots` и шаги в `steps`. Отметки на снимке (`marks`) задаются в процентах снимка: `tap` — касание, `box` — рамка, `swipe` — жест; `n` — номер шага, `badge` — где стоит номер. `crop`/`cropx` — какую часть снимка показать, `stack` — снимки компьютера друг под другом, `frame: plain` — картинка без рамки телефона. Исключение — `word-selection/`: там нет `guide.json`, README — таблица, и `render.py --all` эту папку не пересобирает.
3. Для рилс добавьте в `guide.json` блок `reel`: `hook` (заголовок обложки), `lead`, `cover` (снимок для обложки), `cta` и `cta_lead` (финальный кадр). Чистые экраны положите в `screens/` (JPEG, строка состояния обрезана), записи экрана — в `video/`:

```bash
adb shell screenrecord --time-limit 20 /sdcard/rec.mp4   # потом adb pull и adb shell rm
ffmpeg -i rec.mp4 -vf "crop=1080:2240:0:100" -c:v libx264 -crf 24 -preset slow -pix_fmt yuv420p -movflags +faststart -an video/1-<шаг>.mp4
```

4. Соберите картинки и README:

```bash
python3 docs/guides/_tools/render.py docs/guides/<папка>
```

Нужны Python, Pillow, Playwright для Python и установленный Google Chrome. `--all` пересобирает все папки.
