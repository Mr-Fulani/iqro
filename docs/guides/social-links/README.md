# Ссылки на сайт из соцсетей: какую куда вставить

Это памятка для владельца, а не материал для постов. К обычной ссылке на сайт добавляется
«хвост» из трёх меток. Человек видит тот же сайт, а в Google Analytics и Яндекс Метрике
становится видно, из какой соцсети и из какого поста он пришёл.

Сайт такие ссылки принимает: страница открывается как обычно, язык выбирается сам, на скорость
и на поиск Google метки не влияют (проверено 19.11.2026, проверка закреплена тестом).

## 1. Ссылки для профилей

Скопируйте строку целиком и вставьте в поле «Сайт» / «Ссылка» в профиле.

| Соцсеть | Что вставить в профиль |
|---|---|
| Instagram `iqro.forum` | `https://iqro.forum/?utm_source=instagram&utm_medium=social&utm_campaign=profile` |
| TikTok `@iqro.forum` | `https://iqro.forum/?utm_source=tiktok&utm_medium=social&utm_campaign=profile` |
| Threads `@iqro.forum` | `https://iqro.forum/?utm_source=threads&utm_medium=social&utm_campaign=profile` |
| Facebook, страница IQRO | `https://iqro.forum/?utm_source=facebook&utm_medium=social&utm_campaign=profile` |
| YouTube, канал IQRO | `https://iqro.forum/?utm_source=youtube&utm_medium=social&utm_campaign=profile` |
| Reddit `iqroforum` | `https://iqro.forum/?utm_source=reddit&utm_medium=social&utm_campaign=profile` |

Состояние на 19.11.2026: в Instagram, Threads, Facebook («Информация» → «Ссылки») и YouTube
(«Настройка канала» → «Профиль» → «Ссылки») ссылки с метками стоят. Остальные:

- **TikTok** — у обычного аккаунта поля для сайта нет; оно появляется у бизнес-аккаунта.
- **Pinterest** — сайт подтверждён как домен `iqro.forum`, поле заблокировано; менять не нужно.
  Метки ставятся в ссылках самих пинов (`utm_source=pinterest`).
- **Telegram** — в описании канала ссылки на сайт нет. Метки ставятся в ссылках в постах
  (`utm_source=telegram`).
- **Reddit** — ссылку в профиле («Настройки» → «Профиль» → «Ссылки на соцсети») владелец
  ставит сам.

Вставлять нужно **в самой соцсети**: приложение Instagram, TikTok или Threads → свой профиль →
«Редактировать профиль» → поле со ссылкой на сайт. Старую ссылку `https://iqro.forum` сотрите и
поставьте новую вместо неё.

**Не в админке сайта.** В админке, в разделе «Социальные сети», поле «Ссылка на профиль» — это
адрес самой соцсети (например `https://www.instagram.com/iqro.forum/`), его сайт показывает в
подвале. Там ничего менять не нужно; ссылку с метками админка и не примет.

Ссылку в профиле достаточно поставить один раз и больше не менять.

## 2. Шаблон для постов, сторис и роликов

```text
https://iqro.forum/<раздел>?utm_source=<соцсеть>&utm_medium=social&utm_campaign=<название-поста>
```

Меняются три места:

- `<раздел>` — куда ведём человека (список ниже). Если ведём на главную, раздел не пишем:
  `https://iqro.forum/?utm_source=...`.
- `<соцсеть>` — `instagram`, `tiktok`, `threads`, `facebook`, `youtube`, `telegram`, `pinterest`
  или `reddit`. Всегда так, маленькими латинскими буквами.
- `<название-поста>` — короткое имя поста, которое вы придумываете сами: латинские буквы, цифры
  и дефис, без пробелов и русских букв. Например `names-of-allah`, `azan-reminders`,
  `ramadan-2027`. Одно и то же имя во всех соцсетях — тогда их легко сравнить.

`utm_medium=social` не трогаем никогда.

### Разделы сайта

| Куда ведём | Что писать вместо `<раздел>` |
|---|---|
| Главная | ничего (сразу `?utm_source=...` после `iqro.forum/`) |
| Коран | `quran` |
| Конкретный аят, например 2:255 | `quran/2/255` |
| Аудио, чтецы | `audio` |
| Ду‘а | `dua` |
| Курсы | `courses` |
| Имена Аллаха | `names` |
| Время намаза | `prayer` |
| Календарь | `calendar` |
| Заучивание | `memorization` |

### Готовые примеры

Пост об Именах Аллаха, одна и та же кампания в трёх соцсетях:

```text
https://iqro.forum/names?utm_source=instagram&utm_medium=social&utm_campaign=names-of-allah
https://iqro.forum/names?utm_source=tiktok&utm_medium=social&utm_campaign=names-of-allah
https://iqro.forum/names?utm_source=threads&utm_medium=social&utm_campaign=names-of-allah
```

Сторис с аятом аль-Курси:

```text
https://iqro.forum/quran/2/255?utm_source=instagram&utm_medium=social&utm_campaign=ayat-al-kursi
```

## 3. Частые вопросы

**Ссылку скопировали с сайта кнопкой «Поделиться», и в ней уже есть знак `?`.** Тогда метки
дописываются через `&`, а не через второй `?`:
`...?уже-было=что-то&utm_source=instagram&utm_medium=social&utm_campaign=names-of-allah`.

**Нужно ли писать язык (`/ru`, `/en`)?** Нет. Без языка сайт сам откроется на языке телефона
человека, метки при этом сохраняются.

**Ссылка получилась длинной.** В профиле это не мешает. Сокращатели ссылок (bit.ly и подобные)
лучше не использовать: часть соцсетей им не доверяет.

**Где смотреть результат.** Google Analytics: «Отчёты» → «Источники трафика» → «Привлечение
трафика», столбцы «Источник/канал» и «Кампания». Яндекс Метрика: «Отчёты» → «Источники» →
«Метки UTM».

**Что не меняется.** Ссылки на наши соцсети в подвале сайта остаются обычными, без меток: метки
нужны только на ссылках, которые ведут *на* сайт.
