# Как послушать слово или отрывок аята

Картинки для поста «как пользоваться». Формат 1080 × 1350, по одной на шаг. Снимки сделаны в
приложении на Android (Мусхаф с таджвидом). На сайте всё так же, отличия — на последней картинке.

| Картинка | Подпись |
| --- | --- |
| `01-hold-word.png` | **Удержите слово.** Коснитесь слова и подержите палец полсекунды. Телефон легко дрогнет — слово выделено, по краям ручки, а рядом — панель «▶ Слово». |
| `02-drag.png` | **Не отпуская, ведите палец.** Выделение растёт до нужного слова, даже через несколько аятов. Над пальцем — лупа, чтобы видеть слово под ним. |
| `03-panel.png` | **Панель рядом со словами.** Отпустили палец — над выделением появляется маленькая панель: ▶ слушать, повтор, «⋯» меню аята, ✕ снять выделение. Она никогда не закрывает выбранные слова. |
| `04-listen-repeat.png` | **Слушайте и повторяйте.** ▶ — звучит ровно выбранное. Звучащее слово подсвечено золотом, на панели видно «Слово 2 из 4». Кнопка повтора: 1× → 3× → без конца. |
| `05-handles.png` | **Поправьте края ручками.** Тяните кружок на любом конце выделения, чтобы добавить или убрать слова. Страница при этом не листается. |
| `06-voice.png` | **Чей голос звучит.** Если у выбранного чтеца нет разметки этих слов, их прочитает учебный голос. Панель честно пишет, чей голос звучит. |
| `07-ayah-menu.png` | **Меню аята — через «⋯».** Кнопка «⋯» на панели или касание номера аята открывают прежнее меню: перевод, тафсир, заметка, выучить, поделиться. |
| `08-tajweed.png` | **Цветное слово: звук правила.** Коснитесь цветного слова — откроется карточка таджвида. Сразу под словом: «Прослушать фрагмент» (звучит место правила, у правила на стыке — оба слова) и «Выделить отсюда». |
| `09-site.png` | **На сайте — так же.** На телефоне те же жесты. На компьютере: двойной щелчок — слово, Shift+щелчок — до другого слова, пробел — слушать, Esc — снять. В полноэкранном Мусхафе на телефоне «⋯» открывает действия аята листком снизу. |

Подписи короткие: их можно брать в пост как есть, по одной на картинку.

Как сделаны: настоящие снимки экрана Redmi Note 7 и сайта (Pixel 7, тестовые данные) с
отметками пальца и подписями; HTML-карточки отрисованы Playwright. Подробно о фиче:
[docs/mushaf/word-range-playback.md](../../mushaf/word-range-playback.md).
