# Время намаза: поиск своего города

На странице «Время намаза» появился поиск города: начните печатать название — сайт покажет подходящие города мира, выберите свой, и расписание посчитается для него.

**Где найти:** сайт iqro.forum: «Ещё» → «Время намаза» (на компьютере — «Намаз» в меню).

**Сайт и приложение:** на сайте поиск идёт по большой базе — 172 тысячи населённых пунктов. В приложении тот же поиск: «Ещё» → «Время намаза» → выбор города; без сети остаётся короткий встроенный список.

## Найдите свой город по названию

![Найдите свой город по названию](1-city-search.png)

Напечатайте начало названия города на русском, арабском, турецком или английском и выберите его в списке. Крупные города показаны первыми.
