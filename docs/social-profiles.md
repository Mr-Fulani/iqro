# Социальные профили IQRO

Социальные сети хранятся как общий публичный каталог, а не как ссылки, зашитые в web-футер.
Один и тот же endpoint предназначен для web, мобильного приложения, Telegram Mini App и
будущих промоблоков.

## Управление в админке

Откройте `Админка → Настройки сайта → Социальные сети` и создайте одну запись на платформу.

- `Платформа` определяет иконку, официальное название и допустимые домены.
- `Ссылка на профиль` должна начинаться с `https://` и принадлежать выбранной платформе.
- `Название аккаунта` — необязательная подпись, например `@iqro_forum`.
- `Порядок вывода` сортирует ссылки по возрастанию.
- `Активен` позволяет временно скрыть заполненный профиль без удаления.
- `Добавлять в SEO` включает URL в `Organization.sameAs`.

Пустая ссылка автоматически выключается. В публичный API, футер и SEO попадают только
активные записи с заполненным и прошедшим проверку URL. Удаление или изменение записи
отправляет событие ревалидации: новый список появляется без сборки и деплоя приложения.

## Публичный контракт

`GET /api/v1/site/social-profiles` не требует авторизации и возвращает упорядоченный список:

```json
[
  {
    "platform": "telegram",
    "platform_name": "Telegram",
    "display_name": "@iqro_forum",
    "url": "https://t.me/iqro_forum",
    "sort_order": 10,
    "include_in_seo": true
  }
]
```

Ответ получает публичный `Cache-Control` и `ETag`. Изменения из админки очищают общий API
cache и Next.js tag `site:social-profiles`. Клиенты должны использовать `platform` как
стабильный машинный код, `platform_name` как готовое название и не предполагать фиксированное
количество профилей.

## Web и SEO

Web получает каталог на сервере. Поэтому ссылки присутствуют в исходном HTML, доступны без
JavaScript и не вызывают скачков интерфейса. Футер не показывает пустой социальный блок.
Внешние ссылки открываются в новой вкладке с `noopener noreferrer`; SEO-профили дополнительно
получают `rel="me"`. Активные URL с флагом SEO публикуются в JSON-LD сущности
`Organization.sameAs`, на которую ссылается `WebSite.publisher`.

Иконки и фирменные цвета выбираются клиентом по стабильному коду платформы. Админка не
принимает HTML, SVG или CSS, поэтому содержимое таблицы нельзя использовать для внедрения
разметки либо произвольных стилей.
