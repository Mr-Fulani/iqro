# Календарь Хиджры

Расчёт — локальная таблица Умм аль-Кура из `hijri 3.0.1`, закреплённая в lockfile.
[Пакет и документированный пример](https://pub.dev/packages/hijri),
[исходники](https://github.com/ahmedoid/hijri_date), BSD-2-Clause; лицензии включены
в Flutter bundle и доступны через Настройки → Лицензии компонентов.
Поддерживаемый диапазон таблицы: 14.03.1937–16.11.2077. За пределами — явное сообщение,
никакой приблизительный fallback не выдаётся за Умм аль-Кура.

- Сетка показывает день Хиджры и соответствующий гражданский день; начало недели/RTL
  и цифры следуют локали RU/EN/AR/TR. Поправка пользователя от −2 до +2 дней сохраняется.
- Все операции с гражданскими днями идут через UTC-компоненты, без ошибок DST.
- Главная может учитывать магриб только из имеющегося расписания текущего дня.
  При отсутствии расписания — явная пометка гражданской даты, без догадки о закате.
- Видна оговорка: расчёт не равен местному наблюдению луны; Рамадан/праздники уточняются
  в общине. Дни в сетке не являются официальными объявлениями о начале праздника.
- Данные не запрашиваются у стороннего календарного API и не передают ему геолокацию.

## Отметки и проверенные источники

| Отметка | Основание |
|---|---|
| Рамадан | [Коран 2:185](https://quran.com/2/185) |
| Ид аль-Фитр, Ид аль-Адха | [аль-Бухари 1990](https://sunnah.com/bukhari:1990) |
| Арафа, Ашура | [Муслим 1162b](https://sunnah.com/muslim:1162b) |
| Дни ташрика | [Муслим 1141a](https://sunnah.com/muslim:1141a) |
| Белые дни 13–15 | [Абу Дауд 2449](https://sunnah.com/abudawud:2449) |
| Последние десять ночей Рамадана | [аль-Бухари 2017](https://sunnah.com/bukhari:2017) |

Ид и дни ташрика имеют приоритет: 13 Зуль-хиджа не маркируется как желательный пост.
Для Арафа указана оговорка о паломниках. Ляйлят аль-Кадр не закрепляется за 27-й ночью
как достоверно известная дата. Новые спорные памятные даты без источника не добавляются.
Ссылки доступны в карточке каждого события и общем разделе источников.

Проверки: документированный conversion 12.11.2018 = 4 Раби аль-авваль 1440,
round-trip границ всех месяцев 1400–1500 AH с поправками, закат/устаревший закат,
праздники против добровольного поста, 360px/крупный шрифт/4 локали.
Это техническая проверка, не религиозный редакционный sign-off массового релиза.
