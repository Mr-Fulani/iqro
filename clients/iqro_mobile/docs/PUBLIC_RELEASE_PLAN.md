# IQRO mobile — следующий этап публичного выпуска

Статус: в работе. Наличие нового интерфейса не означает готовность публикации.
Каждый законченный этап: анализ, профильные тесты, проверка Android, commit.

1. Исправить ощутимый отклик при перелистывании/перетягивании страниц, сохранить системный
   opt-out и добавить настройку приложения. Не менять настройки Android автоматически.
2. Инвентаризировать Мусхафы backend/Quran.Foundation/quran.com/JMApps. Подключать только
   проверенные страницы конкретного издания, не смешивать риваяты/нумерацию/аудио.
   Для каждого нового источника фиксировать происхождение, условия, полный набор страниц,
   геометрию аятов, checksum, размер и результат проверки. Не обозначать metadata как готовое издание.
3. Календарь Хиджры: offline-friendly расчёт с явно указанным методом и поправкой,
   календарная сетка, источники значимых дат, оговорка о местном наблюдении луны.
4. Главная IQRO: единый мотив света/арки, читаемая иерархия, действующие переходы,
   календарь и продолжение чтения без декоративных заглушек, RU/EN/AR/TR и крупный текст.
5. Единое качественное оформление портретов и лёгкая анимация существующего знака.
   Загруженные администратором изображения не менять и не перезаписывать.
   Не генерировать лица реальных чтецов. Respect reduced motion, без вечных анимаций/blur.
6. Release gate: полный анализ/тесты, offline/повороты/аудио/слабый Android, доступность,
   подтверждение контента, production URL, signing, privacy/store forms. Публикацию в магазины
   не выполнять без отдельного согласования. Не объявлять неподтверждённые проверки зелёными.

Дисковое пространство не освобождать удалением без отдельного точного разрешения пользователя.
