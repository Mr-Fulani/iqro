# Мобильный веб-интерфейс IQRO

Ветка: `codex/web-mobile-native-parity`. Основа: `9f7d4aa`.

## Эталон и границы

Визуальный эталон — действующий Flutter-клиент:

- `clients/iqro_mobile/lib/core/theme/iqro_theme.dart` — палитра, размеры текста, радиусы и кнопки;
- `clients/iqro_mobile/lib/core/design_system/iqro_widgets.dart` — поля страницы, карточки и заголовки;
- `clients/iqro_mobile/lib/app/app_shell.dart` — пять нижних вкладок;
- экраны `home`, `quran`, `audio`, `plan`, `more`, `calendar` — оформление соответствующих разделов.

Применена светлая палитра мобильного приложения. Изменения ограничены `services/web`. Flutter, backend, API-клиент, авторизация, расчёты, синхронизация, хранение, воспроизведение и рендерер Мусхафа не изменены. Различия в наборе возможностей между клиентами сохранены: например, веб использует свои существующие аудиоконтролы и формы.

## Что изменилось

На ширинах до 768 px применяется `app/mobile.css`, импортированный после общих стилей. На больших ширинах сохраняется десктопное оформление. Статические inline-стили соответствующих контейнеров перенесены в классы; мобильные правила не требуют `!important`.

| Элемент | Мобильное оформление |
| --- | --- |
| Фон / карточка | `#f7f4ec` / `#fffdf8` |
| Основной акцент / тёмная карточка | `#0b5d4a` / `#073e34` |
| Дополнительные поверхности | песочная `#f5ead5`, лавандовая `#ece8f6` |
| Поля страницы / радиус карточки | 16 px / 22 px |
| Основные кнопки / компактные действия | минимум 52 px / 44 px |
| Верхняя / нижняя панель | минимум 64 px / 72 px с учётом safe area |
| Формы | 16 px в полях, перенос длинных подписей, адаптивные колонки |

Нижняя навигация содержит «Главная», «Коран», «План», «Аудио», «Ещё». Все ссылки ведут на существующие локализованные маршруты. «Ещё» открывает панель с намазом, календарём, ду’а, заучиванием и кабинетом. Она работает с клавиатуры, закрывается по Escape и при переходе на другую страницу.

Главная получила карточки в палитре Flutter. По просьбе пользователя 9 сентября восстановлен прежний фотографический баннер с полным заголовком и описанием. Обновлены каталоги чтецов, списки сур и аудио, чтение аятов, формы плана и намаза, календарь, ду’а и общие поверхности кабинета. Ссылки футера доступны в раскрываемой панели.

Переводы, тафсир и точная навигация ридера собраны в раскрываемый блок на телефонах. На десктопе блок открыт. `MobileDisclosure` управляет только HTML-атрибутом `open`: дочерние компоненты постоянно смонтированы, поэтому сворачивание сохраняет поля, запросы и состояние приложения.

Компактный аудиоплеер расположен над нижними вкладками; на планшетной ширине его действия помещаются в одну строку. В режиме Мусхафа нижняя навигация скрыта, а страница на телефоне занимает всю ширину. Координаты выделения аятов, размеры изображений, шрифты Корана и алгоритмы перелистывания не изменены.

## Сохранение поведения

Структурная проверка TSX подтвердила полное совпадение существующих обработчиков `on*`, значений `value` / `checked`, условий `disabled` и ссылок `href` в главной, аудио, ридере и футере относительно исходного коммита.

При проверке обнаружена существовавшая ошибка контракта Next.js: `app/dua/page.tsx` принимал произвольный `initialData`, запрещённый для route entry point. Представление вынесено в `components/DuaCatalogPage.tsx`; в исходном маршруте оставлена обёртка, локализованный маршрут передаёт те же данные напрямую. Содержимое компонента идентично исходному, кроме путей импортов. Это не меняет загрузку, фильтры, состояние и действия каталога.
