# Канонический корпус и страницы

Для нового окружения используйте [локальную разработку](../../../docs/local-development.md):
`make dev-up`, затем `make dev-data`.

Канонический импорт проверяет закреплённый текст и 604 страницы QF 5 без PDF.
Сборщик, привязывавший текст к PDF-изображениям, выведен из эксплуатации.
Импорт ранее проверенного dataset остаётся средством совместимости; новые страницы
для отображения публикуются через `publish_mushaf_rendition`.
